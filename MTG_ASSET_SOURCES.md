# MTG Widget Asset Sources

## MTG-specific symbols

- Mana symbols (font + SVG source): `https://mana.andrewgioia.com/`
  - Notes: Great for `{W}{U}{B}{R}{G}`, tap, energy, etc.
  - License notes on site: Mana font uses SIL OFL 1.1, CSS under MIT; symbol imagery references Wizards IP.

- Set symbols: `https://keyrune.andrewgioia.com/`
  - Notes: Full MTG set icon system, good for deck/set badges.
  - License notes on site: Keyrune font under SIL OFL 1.1; project files under GPL/MIT depending on release docs; set symbols reference Wizards IP.

- Raw MTG vector catalog (set/watermark/misc symbols): `https://github.com/Investigamer/mtg-vectors`
  - Notes: Large SVG library, optimized variants included.
  - Repo license: MPL-2.0.

## Generic UI/icon packs

- Game-icons.net: `https://game-icons.net/`
  - Notes: Great for kill/skull, timer, mana-like utility glyphs.
  - License: CC BY 3.0 (credit required for most icons).

## Background textures / atmospherics

- Handpainted stone textures (CC0): `https://opengameart.org/content/handpainted-stone-texture`
  - Notes: Useful for subtle fantasy panel backdrops.
  - License: CC0.

- Unsplash free backgrounds: `https://unsplash.com/license`
  - Notes: Good for optional player background images.
  - License: Free use with restrictions in Unsplash license page.
